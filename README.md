# SPRED 테스트 버전

오타마톤 악보를 만들고 재생해 보는 웹앱 테스트 버전입니다.

배포 링크를 열면 바로 사용할 수 있습니다.  
따로 설치할 것은 없습니다.

2026-11-02 Android 싱크 임시 실험: 저장된 Local offset이 없는 Android 브라우저는 -220ms로 시작합니다.
기존 저장값(0 포함)은 유지하며 PC/iOS는 기본 0ms입니다. 기존 테스터는 Local offset을 직접 -220으로 입력해 비교할 수 있습니다.
임시 기본값은 자동 저장하지 않으며, 직접 확정한 값만 저장합니다. UA가 Android로 식별되지 않거나 저장소 접근이 실패하면 기본 0ms입니다.
이 변경은 테스트 배포본의 `src/infra/youtube_preferences.ts`와 관련 검사에만 적용한 예외로, 원본 동기화 시 유지·종료 여부를 확인해야 합니다. 실제 보편 지연의 측정 결과를 뜻하지 않습니다.

아직 미완성이라 큰 악보에서는 느려지거나 화면이 깨질 수 있습니다.

현재 해볼 수 있는 것:

- 악보 셀 입력
- JSON 저장 / 불러오기
- 로컬 저장 / 불러오기
- 트랙 선택
- 기본 재생
- 유튜브 영상 싱크 테스트

아직 부족한 것:

- 긴 악보 최적화
- 모바일 편집
- 세부 사용성 정리

유튜브 영상은 영상 주인이 외부 재생을 막아 둔 경우 앱 안에서 재생되지 않을 수 있습니다.

테스트하다가 이상한 점이 있으면 어떤 상황에서 문제가 생겼는지 알려 주세요.
