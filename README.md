# SPRED 테스트 버전

오타마톤 악보를 만들고 재생해 보는 웹앱 테스트 버전입니다.

배포 링크를 열면 바로 사용할 수 있습니다.  
따로 설치할 것은 없습니다.

2026-11-02 Local offset 정책: 저장값이 없으면 Android로 식별되는 브라우저만 -220ms, iOS/iPadOS·Windows 및 그 외 환경은 0ms로 시작합니다.
기존 저장값(0 포함)을 우선하며, 사용자가 변경·확정한 값은 다음 방문에도 유지합니다. 기존 테스터는 Local offset을 직접 -220으로 입력해 비교할 수 있습니다.
환경 기본값은 자동 저장하지 않습니다. 저장값 오염·저장소 접근 실패·기기 판별 불가 시에는 0ms를 사용합니다. 브라우저의 데스크톱 모드 등으로 모바일 판별이 누락될 수 있습니다.
Android는 -220ms, iOS는 0ms에서 맞는다는 사용자 전달 관찰을 반영한 정책이며 모든 기기의 지연을 계측한 결과는 아닙니다. iOS에서 -220ms를 직접 저장했다면 0으로 변경·확정해 주세요. 원본과 배포본은 같은 정책을 사용합니다.

아직 미완성이라 큰 악보에서는 느려지거나 화면이 깨질 수 있습니다.

현재 해볼 수 있는 것:

- 악보 셀 입력
- 터치 편집: 한 손가락으로 입력하고 두 손가락으로 화면 이동. 두 번째 손가락이 닿으면 현재 제스처의 편집은 취소됩니다.
- JSON 저장 / 불러오기
- 로컬 저장 / 불러오기
- 트랙 선택
- 기본 재생
- 유튜브 영상 싱크 테스트

아직 부족한 것:

- 긴 악보 최적화
- 모바일 전체 편집 UI 및 Android/iOS 실기기 검증
- 세부 사용성 정리

유튜브 영상은 영상 주인이 외부 재생을 막아 둔 경우 앱 안에서 재생되지 않을 수 있습니다.

테스트하다가 이상한 점이 있으면 어떤 상황에서 문제가 생겼는지 알려 주세요.
