# SPRED 테스트 버전

오타마톤 악보를 만들고 재생해 보는 웹앱 테스트 버전입니다.

배포 링크를 열면 바로 사용할 수 있습니다.  
따로 설치할 것은 없습니다.

아직 미완성이라 큰 악보에서는 느려지거나 화면이 깨질 수 있습니다.

현재 해볼 수 있는 것:

- 악보 셀 입력
- JSON 저장 / 불러오기
- 로컬 저장 / 불러오기
- 트랙 선택
- 기본 재생
- 유튜브 영상 싱크 테스트

아직 부족한 것:

- 긴 악보 최적화
- 루프 재생
- 모바일 편집
- 세부 사용성 정리

유튜브 영상은 영상 주인이 외부 재생을 막아 둔 경우 앱 안에서 재생되지 않을 수 있습니다.

테스트하다가 이상한 점이 있으면 어떤 상황에서 문제가 생겼는지 알려 주세요.
